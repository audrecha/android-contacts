# Контакты — практика дженериков Kotlin

Проект второго спринта Android-курса Яндекс Практикума. Исходная база — [interactivetextbook/android-contacts](https://github.com/interactivetextbook/android-contacts), ветка `compose-start`.

## Что изменено

`CountryCodeBottomSheet` и `MessengersBottomSheet` используют общий `CommonBottomSheet<T>` по образцу `SortBottomSheet`. Удалена повторяющаяся разметка заголовка, списка и контейнера опций, а также дублирующий обработчик нажатия на строку. Конкретные компоненты передают заголовок, список, выбранное множество и callbacks, сохраняя свою отрисовку опций.

Типы `CountryCode` и `MessagingApp` выводятся компилятором. Множественный выбор остаётся в `Set`, обработчики checkbox и закрытия сохранены.

## Запуск и проверка

Открыть проект в Android Studio с JDK 21 и Android SDK 35. Либо выполнить:

```sh
bash gradlew clean assembleDebug testDebugUnitTest lintDebug
```

Эти проверки также запускаются в GitHub Actions. Debug APK и отчёты доступны в артефактах запуска.

Для ручной проверки на устройстве:

1. В «Кодах стран» выбрать несколько стран нажатием на строку и checkbox; снять одну, закрыть и открыть меню — выбор должен сохраниться.
2. Повторить для нескольких мессенджеров.
3. Совместить оба фильтра и изменить сортировку — выбранные фильтры должны сохраниться.
4. Проверить закрытие кнопкой, свайпом и нажатием вне меню.

Ручные проверки на устройстве/эмуляторе и инспекции Android Studio необходимо выполнять отдельно; успешная CI-сборка сама по себе их не подтверждает.
